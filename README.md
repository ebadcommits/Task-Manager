# ✅ Task Manager

A responsive task management application built with React and Tailwind CSS to practice the core concepts of building interactive React applications.

## 🛠️ Built With

* React
* Vite
* JavaScript (ES6+)
* Tailwind CSS

## ✨ Features

* ➕ Add new tasks
* ✏️ Update task state through user interactions
* 🗑️ Manage and remove tasks
* ☑️ Mark tasks as completed
* 🔄 Dynamic UI updates based on application state
* 📱 Responsive interface
* 🧩 Reusable React components

## 🧠 React Concepts Practiced

This project was built as a hands-on exercise for understanding the fundamentals that form the foundation of most React applications.

### Components

Breaking the interface into smaller, reusable components.

### Props

Passing data and functionality between components.

### State

Using `useState` to manage and update application data.

### Conditional Rendering

Displaying different UI states based on the application's data.

### Lists & `.map()`

Rendering collections of tasks dynamically.

### User Input & Forms

Handling user input and form interactions.

### State Updates

Learning how to update React state correctly while keeping the UI synchronized with the underlying data.

### Component Communication

Passing information and actions between components to create a connected application.

## 🎯 Why I Built This

I built this project to strengthen my React fundamentals by bringing several concepts together into one interactive application.

While the application itself is simple, the concepts behind it are fundamental to building larger React applications such as dashboards, SaaS products, productivity tools, and other data-driven interfaces.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ebadcommits/Task-Manager.git
```

### 2. Navigate to the project

```bash
cd Task-Manager
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available through the local Vite development server.
